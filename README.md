🛒 Superstore Sales Analysis & Profit Prediction

📌 Project Overview

This project focuses on performing end-to-end retail sales analysis using the Superstore dataset. The project includes data cleaning, exploratory data analysis (EDA), business insight generation, data visualization, and machine learning-based profit prediction.

The objective of this project is to analyze sales performance, identify business trends, and build a predictive model for profit estimation using Python and Machine Learning techniques.

Developed as part of a Data Science Internship project.

📊 Dataset Information

Dataset:Superstore Sales Dataset
Domain:Retail Analytics
Source: Kaggle
File Used: `SampleSuperstore.csv`

The dataset contains:
- Sales transactions
- Product categories
- Customer segments
- Regional sales information
- Profit and discount details


🎯 Project Objectives

- Clean and preprocess retail sales data
- Analyze regional and category-wise sales performance
- Visualize business trends and patterns
- Identify factors affecting profitability
- Build a machine learning model to predict profit

🧹 Data Cleaning Process

The following preprocessing steps were performed:

- Removed duplicate records
- Checked and handled missing values
- Converted date columns into proper datetime format
- Verified data consistency and integrity



📈 Exploratory Data Analysis

The project includes detailed analysis of:

✔ Regional Sales Analysis
- Comparison of sales performance across regions
 ✔ Category-wise Profit Analysis
- Identification of profitable product categories
✔ Customer Segment Analysis
- Analysis of sales contribution by customer segments
✔ Monthly Sales Trend
- Visualization of sales growth patterns over time
✔ Correlation Analysis
- Heatmap showing relationships between numerical features

 🤖 Machine Learning Model

A Linear Regression model was developed to predict profit using:

 Input Features
- Sales
- Quantity
- Discount

Target Variable
- Profit



📊 Model Evaluation Metrics

The model performance was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score



💡 Key Business Insights

- Technology products generated higher profits compared to other categories.
- Discounts negatively impacted overall profitability.
- Certain regions consistently outperformed others in sales revenue.
- Seasonal sales trends were observed throughout the year.
